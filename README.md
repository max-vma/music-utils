# Music Utils

Набор небольших утилит для музыкантов.

## 1. [Guitar Scale Visualizer](https://max-vma.github.io/music-utils/)

Инструмент для визуализации музыкальных гамм на гитарном грифе.

#### Функциональность:

##### **Основные возможности:**

- Выбор тоники из 12 нот
- Поддержка гамм:
  - Лидийский
  - Натуральный мажор (ионийский)
  - Миксолидийский
  - Дорийский
  - Натуральный минор (эолийский)
  - Фригийский
  - Локрийский
  - Блюзовый минор
  - Блюзовый мажор

##### **Настройки строя:**

- 6 предустановленных вариантов:
  - E Standard (EADGBE)
  - Drop D
  - Drop C
  - Double Drop D
  - Open D
  - Open C
- Кастомная настройка: индивидуальный выбор ноты для каждой из 6 струн

#### Техническая реализация:

- Vue 3 (Composition API)
- TypeScript
- Pinia (state management)
- Element Plus
- Vite
- Vitest (юнит-тесты)
- ESLint, Prettier, Stylelint
